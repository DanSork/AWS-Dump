\\ Research-based AWS Questions - using google only // 


1. What are AWS Landing Zones, and how do they help with multi-account governance?


Answer: AWS LZ is a service that provides a starting point of which you can deploy workloads and applications - it gives a baseline for multi-account architecture.

AWS LZ enforces controls to ensure compliance with guidelines across multi-account environments which include default accounts, account structure, network and security layouts.

2. Explain how AWS WAF protects web applications from common attacks.

Answer: AWS WAF protects the web applications from common attacks by allowing you to configure specific rules to block or monitor web requests based on the rules you have set.
such as, HTTP/S headers or body, IP addresses or customs URI.


--

3. What is AWS Snowball, and when should it be used?


Answer: AWS Snowball is  a petabyte scale data transport solution that uses secure appliances to transfer large amounts of data in and out of the AWS cloud.
this service is best used for large-scale data transfers  with high data costs and long transfer times.


--

4. What are the key differences between AWS Backup and manual snapshot backups?


Answer: AWS snapshots are point in time copy of your current status/volume on the disk level which is stored in S3 bucket which are created manually and is only replicated across all the AZ in the region.
with AWS Backup makes it easy for you to centralize and automate the backing of data across AWS services. This lets you create polices specific to the service which lets you define requirements such as how frequent you want to backup and how much to keep the backup for all this is done by simply tagging the services.

--

5. How does AWS Shield help mitigate DDoS attacks?


Answer: AWS Shield helps you stop DDoS attacks for AWS services on the network, transport and application layers. The service uses a combination of traffic filtering and real time monitoring to ensure that even at a time of an attack your service/application remains available.


--

6.Explain the differences between AWS Transit Gateway and VPC Peering.


Answer: AWS transit connects your VPC network through a central hub, this simplifies your network and is a solution for complex peering and offers high scalability and management while VPC peering offers a point-to-point peering with limited automation and manual management with routing best used for smaller cases.



--

7. What is AWS Step Functions, and how does it help with workflow automation?


Answer: AWS Step Functions let you create workflows AKA(Also Known As) State Machines. Workflows are a series of even driven steps. Each state represents a unit of work that another AWS service performs. The AWS Step Functions helps you automate workflows via console where you can visualize, edit and debug your workflows. You can easily examine each state of each step in your workflow.



--

8. How does AWS Control Tower assist organizations in managing multiple AWS accounts?


Answer: AWS Control Tower applies mandatory and also optional high-level rules called "Controls" that help you enforce your set policies on the account/s. This service helps you observe and manage every movement to ensure smooth and secure operations, helps the company keep a unified view and also respond quickly. 


--

9. What is the significance of AWS Outposts in hybrid cloud solutions?


Answer: AWS Outposts help you by extending your infrastructure with on-premise environments, AWS Outposts helps you with seamless migration between Cloud and On-Premise while providing low latency access for various applications, workload portability and reducing complexity.

--

10. Explain the key use cases for AWS Elastic File System (EFS) compared to S3 and EBS.


Answer: EFS is Network File System, allows you a shared file system across multiply machines across AZ's.
it's best used for traditional file system interface that needed to be accessed by multiply servers at a time while S3 is an object storage best used for large scale data storage and global accessibility while remaining unstructured. EBS is a block storage and is EC2 based, best for low latency and high performance access to data.
